# Capturi de ecran pentru PR-uri

Fiecare PR care schimbă ce se vede pune aici **doar ecranele schimbate**, desktop și mobil (375 px),
într-un folder pe pas: `docs/screenshots/<pas>/<ecran>-desktop.jpg` și `<ecran>-mobil.jpg`
(ex. `docs/screenshots/3.6-pagina-cos/cos-desktop.jpg`).

JPG, lățimea reală a ecranului, fără date personale. PR-ul le leagă în secțiunea „Capturi”.
