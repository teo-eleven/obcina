# Decizii de arhitectură (ADR)

Deciziile greu de inversat sau neevidente pentru cine citește codul mai târziu stau aici,
câte un fișier numerotat: `NNNN-titlu-scurt.md`, pornind de la `0000-template.md`.

O decizie acceptată nu se rescrie. Dacă ne răzgândim, scriem un ADR nou care o înlocuiește
și pune link înapoi.
