Imaginile generate cu AI sunt marcate ca atare în `alt` și aici.

## Imaginile produselor

- **Acum:** desene provizorii generate din cod de `npm run images` (`scripts/images.mjs`), în paleta
  mărcii. Nu au autor extern.
- **Mai târziu:** imagini generate cu ChatGPT după șablonul din
  [`docs/images/prompturi-borcane.md`](images/prompturi-borcane.md). Când ajung, adăugăm aici
  generatorul și data lotului, iar site-ul le marchează „imagine generată” (pașii 2.8–2.9).
